# Hebrew Daily Report — Mandatory Table Template

Layout approved 2026-09-09 (reference: the first live Hebrew deployment's daily report). Use for ALL kid social-watch daily reports in Hebrew. Tables are MANDATORY — never render these sections as bullet lists. Missing value → "-".

```
📊 דוח יומי — {CHILD_NAME} | {DD.MM.YYYY} ({day-of-week, optional})

🤖 סיכום היום:
[2-3 sentences on social activity, overall tone, mood]

🚩 דגלים אדומים:
[description or "אין." + what was scanned and closed] — cite evidence from the checklist categories

📈 מגמות:

| מדד | ערך |
|---|---|
| WoW | **±X%** (N לעומת M) |
| MoM | **±X%** (N לעומת M — with context, e.g. חזרה ללימודים) |
| היום | N הודעות |
| שבוע | N — ישיר X (Y%) \| קבוצות Z (W%) |
| יוצאים (7 ימים) | X ישירות + Y בקבוצות |

👥 שולחים פעילים (ישיר + קבוצות):

| שולח/ת | סה"כ שבוע | ישירות |
|---|---|---|
| [name] | N | N |
| [name] | N | 0 — קבוצות בלבד |

[5-10 most active senders. After the table — one summary line on the real DM circle: who actually talks to the child directly vs group noise.]

⚡ מעורבות:
• תגובות: N על N הודעות מ-N מגיבים. אמוג'י מוביל: X.
• זמן תגובה חציוני: [contact] ~N דק' | [contact] ~N דק' (מהיר/רגיל/מנותק)

💬 קבוצות פעילות:

| קבוצה | היום | שבוע |
|---|---|---|
| [name] | N | N |

[🗑️ הודעות שנמחקו החודש: (1st-of-month reports only)
[findings or "אין פעילות חריגה"]]

⚠️ הכרעה: **נורמלי / כדאי לבדוק / דורש תשומת לב**
```

## Rules
- Markdown pipe tables render fine in Telegram (verified 2026-09-06) — mandatory here.
- Emoji headers exactly as above; **bold** for key numbers and the verdict.
- Tight and sharp. No fluff. Blunt when something is concerning.
- No PII/real identifiers in this public template — fill at runtime.
